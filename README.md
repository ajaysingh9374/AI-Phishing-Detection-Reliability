# Phishing Detection Reliability

MSc Dissertation Project

This repository contains the experimental notebooks used to evaluate baseline AI-based phishing email detection models under multiple evaluation conditions.

## Models
- Multinomial Naive Bayes
- Logistic Regression
- Linear SVM

## Feature Extraction
- TF-IDF

## Evaluation Conditions
- Random-Split
- Campaign-Aware
- Phishing-Only OOD

## Dataset
CyberSiren NLP Email Classification Dataset v1

## Research Focus
The project investigates whether model rankings and phishing detection performance remain reliable across different evaluation conditions.
